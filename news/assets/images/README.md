# 图片资源目录

## 目录结构

每个新闻事件都有一个以日期命名的文件夹，包含：

```
20240406/
├── thumb_1.jpg    # 缩略图1 (建议300x300px)
├── thumb_2.jpg    # 缩略图2
├── thumb_3.jpg    # 缩略图3
├── full_1.jpg     # 原图1 (高清版本)
├── full_2.jpg     # 原图2
└── full_3.jpg     # 原图3
```

## 图片规范

### 缩略图 (thumbnail)
- 文件名：`thumb_*.jpg`
- 建议尺寸：300x300px
- 文件大小：< 50KB
- 格式：JPG/JPEG

### 原图 (full)
- 文件名：`full_*.jpg`
- 建议最大宽度：1920px
- 文件大小：< 2MB
- 格式：JPG/JPEG

## 注意事项

1. 图片文件名必须与JSON数据中的路径一致
2. 建议使用压缩工具优化图片大小
3. 确保图片版权合规
4. 为每张图片提供合适的alt描述

## 占位图片
